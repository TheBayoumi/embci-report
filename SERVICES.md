# Paid integration services

`embci-report` is open source. Paid work is available for teams that want a production-ready integration without building and maintaining the adapter themselves.

## Fixed-scope offers

### Integration assessment — $49

A written assessment for one sanitized report format or CI pipeline.

Deliverables:

- compatibility assessment
- recommended integration path
- input-schema mapping
- implementation estimate and risks

This is suitable when you need a concrete answer before committing to implementation.

### Generic adapter — from $149

A tested adapter that converts one documented, non-confidential input format into the public `embci-report` JSON schema.

Typical deliverables:

- adapter implementation
- automated tests using fictional or sanitized fixtures
- CLI documentation
- reproducible validation commands

Final scope depends on format complexity and whether a public specification exists.

### CI integration pack — from $299

Repository-specific integration for an existing CI pipeline.

Typical deliverables:

- GitHub Actions or GitLab CI integration
- threshold and exit-code policy
- generated Markdown or HTML evidence
- tests and operating documentation

## Requesting work

Open an **Integration request** issue using fictional or sanitized examples only. For non-public commercial discussions, email `mahmoud.bayoumi.pp@gmail.com` with the repository link and a short description of the required output.

Do not send proprietary source code, employer-owned reports, credentials, customer data, or licensed vendor exports before a written scope and handling agreement exist.

## Delivery boundaries

Paid services do not include:

- access to employer or customer systems
- reverse engineering proprietary formats without authorization
- guaranteed compatibility with undocumented vendor behavior
- safety certification or legal compliance approval
- unlimited revisions or unbounded support

Each engagement receives a written scope, acceptance criteria, price, and delivery format before implementation starts.
