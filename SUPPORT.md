# Supporting embci-report

`embci-report` is maintained as a useful public open-source tool. Sponsorship funds maintenance, documentation, generic adapters, and reusable CI integrations.

## Sponsors status

The GitHub Sponsors application is currently pending. The sponsor button may not lead to an active profile until GitHub approves and publishes the listing.

The private integration kit has already been created and transferred to the organization-owned private repository `TheBayoumi-Labs/embci-report-sponsor-kit`. Access is not active yet. Once the Sponsors listing is approved, the repository will be attached to the eligible tiers so GitHub can manage sponsor access automatically.

## Planned monthly tiers

### Supporter — $5/month

- Optional name in `ACKNOWLEDGEMENTS.md`.
- Monthly project update.

### Integration Kit — $15/month

- Everything in Supporter.
- Access to the private integration kit.
- JUnit XML and generic CSV adapters.
- GitHub Actions and GitLab CI templates.
- Early access to new vendor-neutral integrations.

### Compatibility Partner — $40/month

- Everything in Integration Kit.
- Priority issue triage.
- One bounded compatibility request per month, subject to feasibility.

## Boundaries

Sponsorship does not include:

- guaranteed delivery dates
- access to employer or customer code
- custom work involving confidential or proprietary input data
- vendor reverse engineering
- support for illegal, unsafe, or license-violating use

Compatibility requests must use public specifications, fictional examples, or properly sanitized data.
