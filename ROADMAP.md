# Roadmap

The roadmap is directional rather than a delivery guarantee.

## Available now

- JSON input validation
- Markdown and HTML report generation
- grouped failed-test diagnostics
- statement, function, and MCDC coverage summaries
- configurable coverage thresholds and CI exit codes
- automated test and dependency workflows

## Sponsor kit implemented

- JUnit XML adapter
- generic CSV adapter
- GitHub Actions template
- GitLab CI template
- fictional integration examples
- automated adapter validation

These private assets now reside in the organization-owned repository `TheBayoumi-Labs/embci-report-sponsor-kit`. They will become a tier benefit after GitHub Sponsors approval and tier-based repository access configuration.

## Next public work

- document the JSON schema formally
- improve CLI diagnostics
- add report fixtures and end-to-end tests
- publish installation and release guidance

## Candidate integrations

- SARIF annotations
- historical trend reports
- Cobertura coverage import
- generic JSON mapping configuration
- pull-request summary comments

Priorities will be based on reproducible user needs, maintenance cost, and confidentiality-safe inputs.
