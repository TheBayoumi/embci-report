# Sponsor-supported product plan

## Positioning

Public promise: concise, vendor-neutral reporting for embedded test and coverage pipelines.

Avoid claiming direct support for proprietary tools until a lawful, tested adapter exists.

## Suggested GitHub Sponsors tiers

### $5/month — Supporter
- Name in the supporter list, when requested
- Early release notes
- Vote on the public roadmap

### $15/month — Pipeline Templates
- Access to a private organization-owned repository
- Generic CI templates and adapters
- Monthly compatibility pack

### $40/month — Maintainer Circle
- Everything above
- Priority issue triage
- One documented compatibility request per month, subject to feasibility and licensing

Keep benefits bounded. Do not promise consulting calls, custom development, or response times if the goal is low maintenance.

## Automation loop

1. Pull requests run tests and linting automatically.
2. Dependabot checks dependencies monthly.
3. Weekly health workflow opens an issue only when attention is required.
4. Monthly workflow creates a factual content draft for manual review.
5. GitHub Sponsors automatically grants/removes private-repository access for eligible tiers.

## Launch checklist

- Publish public repository under `TheBayoumi/embci-report`.
- Keep the bundled example fictional, non-confidential, and green.
- Add two screenshots of generated reports.
- Apply for GitHub Sponsors and complete bank/tax verification.
- Create an organization and sponsor-only private repository.
- Add the private repository to the $15 and $40 tiers.
- Publish one technical article demonstrating a real, non-confidential use case.

## Maintenance target

Aim for one supervised review block per week. Fully unattended publishing is deliberately avoided because inaccurate technical claims or broken releases damage trust.
